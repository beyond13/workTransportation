## 進め方

1. Excelを社内の許可された作業場所に保存し、対象環境・基準日・担当者を記入する。
2. 必要に応じてPrompt本文を新規GPT対話へ貼り付ける。実リソース・ユーザ明細・実測ファイルは送信せず、操作手順や数式の相談に利用する。
3. 使用可能な既存CLI／照会ツールを15分で判断する。準備に時間がかかる場合はSetup画面での確認を先行する。
4. 権限定義、Role・Queue・公開グループ、共有設定、ユーザ・割当、カスタムメタデータ・タブの順に取得する。
5. 明細を01～04へ記入し、00で取得元総件数と登録件数を照合する。
6. 代表ユーザと共有ルールを抽出確認し、未確認事項と次の依頼を明記する。

初版の作業目安は1人日。環境準備・件数・権限によって調整する。大量の設定は一覧取得を優先し、詳細を抽出確認した場合は範囲を記録する。

## 完了条件

- [ ] 対象環境、調査基準日、対象範囲を記録した。
- [ ] 各リソース種別の一覧・件数、または取得できない理由を記録した。
- [ ] Profile・権限セット等の主要設定、ロール階層、Queue・公開グループの主要関連を記録した。
- [ ] OWDおよび共有ルールを記録した。
- [ ] ユーザと権限・所属関連を区別して記録した。
- [ ] 一意識別子、ページング、重複、標準／カスタム／パッケージの範囲を確認した。
- [ ] 取得元総件数と登録件数の差異を確認し、未解消分を確認事項に残した。
- [ ] 調査結果の要点、未確認事項、次の対応を整理した。

## 集計上の注意

- 登録件数は識別子が入力された明細行数。組織総件数や自動重複排除件数ではない。
- 未取得の総件数は空欄とし、確認できた0件だけ0を入力する。
- 取得状況は手入力。件数の一致だけでは確認済にしない。
- 03上段は1ユーザ1行、下段は1関連1行。関連数をユーザ数として数えない。
- 公開グループ・Queueの直接メンバー数は、最終的な所属ユーザ数と一致するとは限らない。
- 明細の追加はExcelテーブル行として行う。03上段の拡張時は下段の上に行を挿入して空間を確保する。
- 本セットは空白テンプレートと汎用手順。実データを記入した調査結果・ローカル出力は社内の指定場所で管理する。
